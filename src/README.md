# Source Layout

`src/opticargo_knowledge_graph/` menjadi satu-satunya package Python repository ini. File source masih kosong; README pada package dan subpackage mendefinisikan tanggung jawab, contract, dependency, observability, serta test yang harus membuktikan implementasinya.

Package harus menghasilkan query library, graph synchronization worker, reconciliation command, schema migration tooling, healthcheck, dan CLI diagnostic tanpa membuka public HTTP service.
