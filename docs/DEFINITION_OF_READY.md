# Definition of Ready

Capability siap diimplementasikan bila:

- requirement dan acceptance criteria jelas;
- owner data/runtime/consumer diketahui;
- Shared/event/entity/schema/query version tersedia;
- canonical PostgreSQL source contract tersedia;
- graph label/relation/property dan sensitive-data boundary disetujui;
- failure/retry/idempotency/ACK/DLQ/recovery behavior ditentukan;
- test fixture, dependency mode, dan evidence ditentukan;
- migration/rollback/rebuild dan observability impact dinilai;
- open decision yang menghalangi scope telah ditutup.
