# Initial GitHub Push

```bash
unzip opticargo-knowledge-graph-implementation-skeleton.zip
cd opticargo-knowledge-graph
git init
git add .
git commit -m "chore: initialize knowledge graph implementation skeleton"
git branch -M main
git remote add origin <REPOSITORY_URL>
git push -u origin main
```

Initial commit hanya menyatakan struktur dan dokumentasi tersedia. Jangan memberi label implementation-ready, integration-ready, atau release-ready sebelum source, migration, test, dan evidence tersedia.
